# Scripts de Benchmarking y Perfilado (`scripts/`)

Espacio para automatizar:
* Campañas de medición en hardware real (`512x512`, `1920x1080`, `3840x2160`).
* Captura de contadores con `perf` (CPU), herramientas del fabricante (GPU) y ciclos/JTAG (FPGA).
* Generación de tablas y gráficas de *speedup*, eficiencia paralela y escalabilidad.
